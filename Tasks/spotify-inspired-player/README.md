# Pulse — Spotify-inspired Music Player

A responsive portfolio project based on the layout of the provided music-player reference. Built with **plain HTML, CSS, and JavaScript**; no React, server, API key, or build step required.

## Run it

1. Extract `Pulse-Music-Player.zip` (or open this folder).
2. Open `index.html` in Chrome/Edge. Alternatively, open the folder in VS Code and select **Open with Live Server**.
3. Click any song or playlist to start playing the included original demo instrumentals.

## Features

- Responsive dark layout, library, playlist pages, search, and playable queue.
- Real audio playback: play/pause, seek, previous/next, shuffle, repeat, volume and mute.
- Create personal empty playlists; keep playlists and liked tracks in browser storage.
- Keyboard shortcuts: `/` for search and Space for play/pause (outside inputs).
- Six short, originally synthesized demo instrumentals are bundled under `audio/` to work offline.
- Artwork is generated specifically for this project and is under `assets/`.

**Important:** This is an independent design demonstration, not Spotify or a Spotify integration. The songs here are original short instrumental demos, not licensed commercial recordings. Streaming full commercial music would require a permitted provider or appropriate music licenses. The optional Google Fonts import needs internet access; system-font fallback works offline.
